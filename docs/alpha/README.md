# Alpha archive

Everything in this folder documents the **Bevy/Avian alpha** (branch `alpha-early`) and its
superseded plans. Kept as design reference and salvage maps — several files contain hard-won
measurements and designs that still apply (roads v2, BeamNG lessons, flora, buildings,
shadows, water, engine/netcode discussions).

Cross-links inside these files reflect the old layout and may be stale; they are archived
as-is. **Current direction:** `../VISION.md`, `../ROADMAP.md`, `../ARCHITECTURE.md`,
`../plans/rearchitecture.md`, and the single-file overview `../MASTER.md`.
